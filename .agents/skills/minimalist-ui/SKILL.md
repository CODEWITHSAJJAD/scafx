# Minimalist UI Protocol

- Strict monochrome / obsidian palette with subtle borders (`1px solid rgba(255,255,255,0.08)`).
- Editorial typography with clean contrast (sans + mono).
- Bento grid layouts and flat cards with ultra-diffuse borders.
- Zero emojis; replace with clean SVG icons or monospace glyphs.
- Zero AI copywriting clichés (no "Elevate", "Seamless", "Unleash").
