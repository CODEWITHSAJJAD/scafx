# shadcn/ui

A framework for building UI, components, and design systems.
- Use existing semantic tokens (`bg-background`, `text-muted-foreground`, `border-border`).
- Compose accessible primitives (Tabs, Cards, Buttons, Dialogs, Dropdowns).
- Use `cn()` utility for conditional classes.
