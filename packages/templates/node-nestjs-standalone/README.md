## Features

- NestJS modular architecture with TypeScript
- Dependency injection with `@Injectable()` and `@Controller()`

- CORS enabled by default
- Environment variable configuration via `dotenv`

## Getting Started

### Prerequisites

- Node.js >= 18.0.0
- npm, pnpm, or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build and Run

```bash
npm run build
npm start
```
